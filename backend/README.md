# Task Us — Backend (API)

API REST + Socket.IO du monorepo **Task Us** (Node.js, TypeScript, Express, Sequelize, PostgreSQL).

```bash
cp .env.example .env
npm install
npm run db:migrate
npm run dev
```

Toute la documentation (variables d'environnement, schéma, endpoints, temps réel, push) se trouve dans le [README principal](../README.md#backend).
